# 문서 가이드라인

## 페어 문서

모든 컨벤션 문서는 쌍으로 존재합니다:

```
docs/
  en/<topic>.md   ← 영어 (에이전트 기본 참조)
  ko/<topic>.md   ← 한국어 (한국어 기여자 기본 참조)
apps/api/docs/
  en/<topic>.md
  ko/<topic>.md
```

한쪽을 수정하면 같은 커밋에서 반대쪽도 업데이트합니다.

## 파일명

- 파일명: `kebab-case.md`
- `index.md`는 각 언어 폴더의 진입점

## 문서화 대상

| 범주 | 위치 |
|------|------|
| 프로젝트 전반 컨벤션 (문서 형식, 커밋 스타일) | `docs/` |
| 앱별 아키텍처, DDD, 테스트, 에러 처리 | `apps/<name>/docs/` |

## 문서화하지 않을 것

- 자명한 코드
- 코드 주석이나 타입 정의로 이미 설명된 세부 내용
- Git 히스토리 (대신 `git log` 사용)

## 문서 최신 유지

`.claude/rules/doc-sync.md` 규칙에 따라, 코드 변경 시 관련 문서도 같은 커밋에서 업데이트합니다. 애매하면 관련 `index.md`를 먼저 업데이트합니다.
